# C++内存对齐与布局

## 1.内存对齐的原因
1. CPU访问效率：对齐数据一次读取，未对齐需多次读取+拼接，极大降低效率
2. 硬件要求：部分平台不支持未对齐访问，直接崩溃

## 2.核心对齐规则
1.基本类型：alignof(T)=类型大小（x86_64)
2.结构体规则：
    - 成员偏移量=自身对齐值的整数倍
    - 总大小=最大成员对齐值的整数倍
3.编译器自动填充字节实现对齐

## 3.关键关键字
- alignof(T): 获取类型对齐值
- alignas(N): 强制指定对齐值（2的幂）
- offsetof(Struct,Member): 获取成员偏移量

## 4.手动控制对齐
1. #pragma pack(n): 指定对齐系数
2. _attribute_((aligned(n))): GCC强制对齐
3. _attribute_((packed)): 取消填充

## 5.内存池对齐
1. 内存池必须保证分配的内存对齐
2. 对齐公式：align_size=(size+align-1) & ~(align-1)
3. 统一按8/16字节对齐，适配所有类型
